✅ DEPLOYMENT CHECKLIST

BEFORE YOU DEPLOY:
  ☐ Create MongoDB Atlas account & get connection string
  ☐ Create Render account
  ☐ Create Vercel account
  ☐ Connect GitHub repository
  ☐ Generate JWT_SECRET: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
  ☐ Update environment variables (see DEPLOYMENT_GUIDE.md)
  ☐ Test locally (see LOCAL_TESTING.md)

DEPLOYMENT STEPS:
  ☐ Deploy backend to Render (5-10 minutes)
  ☐ Deploy frontend to Vercel (5 minutes)
  ☐ Update URLs in both services
  ☐ Verify health check: https://your-backend.onrender.com/api/health
  ☐ Test login flow end-to-end
  ☐ Check database for data
  ☐ Monitor logs for errors
